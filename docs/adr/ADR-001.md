# ADR-001: Monolito modular con puntos de separación

- **Tipo:** Arquitectónica
- **Estatus:** Aceptado

## Contexto
El volumen inicial es bajo pero puede crecer.

## Decisión
Un monolito modular (pedidos, inventario, pagos, envíos, notificaciones) que se comunica internamente por eventos.

## Justificación
Simplicidad inicial y facilidad para separar después los componentes de mayor carga.

## Consecuencias
Los módulos deben respetar sus límites para no acoplarse.
