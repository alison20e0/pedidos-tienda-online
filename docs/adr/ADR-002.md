# ADR-002: Reservar stock con UPDATE atómico y RabbitMQ para eventos

- **Tipo:** Tecnológica
- **Estatus:** Aceptado

## Contexto
Hay que evitar la sobreventa y desacoplar notificaciones y envíos.

## Decisión
Reservar con UPDATE ... WHERE stock - reservado >= cantidad en PostgreSQL y publicar eventos en RabbitMQ.

## Justificación
La base de datos garantiza la regla bajo concurrencia; la mensajería aísla tareas lentas.

## Consecuencias
Hay que liberar reservas vencidas y manejar mensajes duplicados.
